# dndvtt — Online D&D Virtual Tabletop

A browser-based virtual tabletop for remote D&D sessions, designed around a balanced layout with participant video above the map and an initiative sidebar.

## Project status

The v0.1.0 foundation source package is being imported. This repository is not yet a complete runnable application.

## Planned stack

- React, TypeScript, Vite
- Node.js, Fastify, Socket.IO
- LiveKit for future real-time audio/video
- SQLite for future campaign persistence

## Initial scope

Room creation and joining, synchronized maps and tokens, initiative tracking, dice rolls, and DM/player permissions.

Video/audio, durable persistence, and production-grade access control are not yet implemented.
